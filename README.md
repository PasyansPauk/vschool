# vSchool — Школьный Дневник МЭШ для iOS

Современное, минималистичное и эстетичное мобильное приложение школьного электронного дневника (МЭШ) для iOS, разработанное на Dart и Flutter.

Дизайн вдохновлен стандартами **Apple Human Interface Guidelines** и концепцией **Samsung One UI**: строгая монохромная черно-белая палитра, высокая контрастность, карточки со скруглением 20–24px, тонкие аккуратные рамки и плавная работа интерфейса.

---

## ✨ Основные возможности

1. **Авторизация через Mos.ID (СУДИР)**
   - Поддержка перенаправления на официальный портал `login.mos.ru`.
   - Режим быстрого демо-входа для локального тестирования и оценки интерфейса.
   - Надежное хранение сессии и токенов авторизации.

2. **Расписание уроков (Электронный дневник МЭШ)**
   - Горизонтальная панель переключения дней недели (ПН – ПТ).
   - Подробная информация по каждому уроку: порядковый номер, время звонков, кабинет (напр. *«Каб. 304»*), ФИО преподавателя (*«Смирнова Елена Викторовна»*), тема урока.
   - Бейджи домашних заданий и полученных на занятии оценок.
   - Pull-to-refresh для обновления данных из сети.

3. **Оценки и Успеваемость с весами МЭШ**
   - Расчет точного взвешенного среднего балла по официальной формуле МЭШ:  
     $$\text{Средний балл} = \frac{\sum (\text{оценка} \times \text{вес})}{\sum \text{вес}}$$
   - Отображение весовых коэффициентов в виде верхних индексов ($5^2, 4^1, 5^3$).
   - Детальный экран по каждому предмету с историей оценок, темами проверочных работ и датами.

4. **Домашние задания**
   - Фильтрация: *«Все»*, *«На завтра»*, *«Сделано»*.
   - Интерактивный чекбокс выполнения с мгновенной синхронизацией с локальным кэшем.
   - Отображение сроков сдачи и количества прикрепленных материалов.

5. **⏱️ Интерактивный «Школа-Трекер»**
   - Живой посекундный таймер: сколько часов, минут и секунд проведено в школе сегодня и сколько осталось до конца занятий.
   - Круговое кольцо прогресса учебного дня.
   - Фокус-карточка текущего события: обратный отсчет до звонка на перемену или до начала следующего урока.
   - Режим быстрой симуляции для демонстрации трекера в любое время суток.

6. **Офлайн-режим и умная защита от VPN**
   - Полноценная локальная работа через кэш (`SharedPreferences`).
   - При отсутствии интернета или блокировке доступа со стороны зарубежных VPN всплывает информационное окно с подсказкой.
   - При закрытии окна пользователю моментально доступно сохраненное расписание, оценки и кабинеты.
   - Кнопка в профиле для симуляции сбоя сети и проверки офлайн-сценариев.

## 🛠️ Стек технологий

- **Платформа**: iOS (iPhone, iPad)
- **Фреймворк**: Flutter 3.44+
- **Язык**: Dart 3.12+
- **UI Kit**: Cupertino (нативный iOS)
- **Хранилище**: `shared_preferences`
- **Сетевой стек**: `http`, `url_launcher`
- **Локализация**: `intl` (русский язык)

## 🚀 Запуск проекта

### Требования
- macOS с установленным Xcode 16+
- Flutter SDK

### Установка зависимостей
```bash
flutter pub get
```

### Запуск тестов и статического анализа
```bash
flutter test
flutter analyze
```

### Запуск на симуляторе или физическом iPhone
```bash
# В симуляторе:
flutter run

# На физическом устройстве в Release-режиме:
flutter run --release
```
