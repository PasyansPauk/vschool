## ✨ Возможности

### 📅 Расписание
- Отображение уроков и перемен с точным временем
- Листание по неделям свайпом влево/вправо
- Перемены отображаются отдельно от уроков
- Цветные эмодзи для каждого предмета
- Мотивирующие цитаты в конце дня / «Ура, уроки кончились!» когда учёба завершена
- Контекстное меню с превью урока (долгое нажатие)

### 📝 Домашние задания
- Список ДЗ с возможностью отмечать выполненные
- Мгновенное визуальное обновление при отметке
- Детальный просмотр задания по нажатию
- Скачивание прикреплённых файлов и материалов
- Фильтрация по предмету
- Контекстное меню (долгое нажатие)

### 📊 Оценки
- Оценки по всем предметам из журнала МЭШ
- Детальная история оценок с датами и комментариями
- Контекстное меню для быстрого просмотра
- Средний балл по предмету

### 👤 Профиль
- Аватар и имя из Мос.ID
- Информация о школе и классе
- Выход из аккаунта

### 🎨 Нативный iOS-дизайн
- Полностью Cupertino UI — выглядит как родное приложение
- **Тактильный отклик** (haptic feedback) везде: смена вкладок, свайпы, нажатия
- **Контекстные меню** с анимацией превью (iOS-style long press)
- Свайп для смены недели
- Плавная навигация и анимации

## 📲 Установка (без App Store)

Так как приложение не опубликовано в App Store, его можно установить через сайдлоадинг. Ниже — несколько способов.

> **Важно:** вам понадобится файл `vSchool.ipa` из раздела [Releases](https://github.com/PasyansPauk/vschool/releases/latest).

---

### Способ 1 — Scarlet (рекомендуется)

[Scarlet](https://usescarlet.com) — бесплатный установщик IPA прямо на iPhone, не требует компьютера.

1. Откройте на iPhone сайт **[usescarlet.com](https://usescarlet.com)** и установите Scarlet.
2. Разрешите доверие профилю: **Настройки → Основные → VPN и управление устройством → Доверять**.
3. Скачайте `vSchool.ipa` из [Releases](https://github.com/PasyansPauk/vschool/releases/latest) прямо на iPhone (Safari → «Загрузить связанный файл»).
4. Откройте Scarlet → нажмите **+** → выберите скачанный `.ipa`.
5. Готово! Найдите vSchool на рабочем столе.

---

### Способ 2 — AltStore

[AltStore](https://altstore.io) подписывает IPA вашим Apple ID и обновляет подпись каждые 7 дней через Wi-Fi.

1. Установите **AltServer** на Mac/PC с сайта [altstore.io](https://altstore.io).
2. Подключите iPhone к компьютеру, откройте AltServer → Install AltStore.
3. На iPhone разрешите доверие профилю AltStore.
4. Скачайте `vSchool.ipa` на iPhone или на компьютер.
5. Откройте AltStore → нажмите **+** → выберите `.ipa`.
6. Введите Apple ID и пароль приложений (app-specific password).
7. Раз в 7 дней держите iPhone в той же Wi-Fi сети с запущенным AltServer — подпись продлится автоматически.

---

### Способ 3 — Sideloadly

[Sideloadly](https://sideloadly.io) — установщик IPA через кабель с Mac/PC.

1. Скачайте и установите **Sideloadly** с [sideloadly.io](https://sideloadly.io).
2. Подключите iPhone к компьютеру через кабель.
3. Откройте Sideloadly, перетащите `vSchool.ipa` в окно программы.
4. Введите ваш Apple ID и пароль приложений.
5. Нажмите **Start** — приложение установится.
6. На iPhone: **Настройки → Основные → VPN и управление устройством → Доверять**.

---

### Способ 4 — TrollStore (только совместимые прошивки)

[TrollStore](https://github.com/opa334/TrollStore) — постоянная установка IPA без переподписи, работает на iOS 14–16.x (определённые версии).

1. Проверьте совместимость вашего устройства на сайте TrollStore.
2. Установите TrollStore по инструкции из официального репозитория.
3. Скачайте `vSchool.ipa` на iPhone.
4. Откройте TrollStore → нажмите **+** → выберите `.ipa` → **Install**.
5. Готово — приложение установлено навсегда без истечения подписи.

## 🔧 Сборка из исходников

Требования:
- macOS 13+
- Xcode 15+
- Flutter SDK 3.x
- iPhone или симулятор (iOS 16+)
- Аккаунт разработчика Apple (для установки на устройство)

```bash
# Клонировать репозиторий
git clone https://github.com/PasyansPauk/vschool.git
cd vschool

# Установить зависимости
flutter pub get

# Запустить в режиме отладки (симулятор или устройство)
flutter run

# Собрать релизный IPA
flutter build ios --release
# Затем упаковать .app в .ipa:
mkdir -p Payload
cp -r build/ios/iphoneos/Runner.app Payload/
zip -r vSchool.ipa Payload/
```
